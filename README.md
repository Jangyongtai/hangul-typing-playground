# 한글 타자 놀이터 (Hangul Typing Playground)

아이들을 위한 한글 타자 겸 한국어 공부 웹앱이에요. 화면 안내는 한국어와 영어로 바꿔 볼 수 있어요.

- **연습:** 자리 익히기(9단계), 낱말 연습(그림, 발음, 뜻), 짧은 글
- **게임:** 단어비, 풍선 팡팡, 타자 레이스(나와 컴퓨터 3명이 4레인에서 경주)
- **사용자 등록:** 이름과 캐릭터만 고르면 돼요. 기록은 그 기기의 브라우저에 저장돼요.
- **입력:** 한글 입력기가 없어도 돼요. 영문 자판을 그대로 쳐도 앱이 두벌식으로 조합해요. 폰·태블릿에서는 화면 자판을 써요.

## 파일 구조

| 파일 | 내용 |
|---|---|
| `src/js/config.js` | **난이도·속도·점수 조정값 (여기만 고치면 됨)** |
| `src/js/data.js` | 낱말, 문장, 공부 팁, 배지, 화면 문구(한/영) |
| `src/js/hangul.js` | 두벌식 한글 조합기 |
| `src/js/audio.js` | 8비트 효과음, 읽어주기 |
| `src/js/store.js` | 사용자별 기록 저장. 나중에 로그인/서버로 바꿀 때 이 파일만 고치면 됨 |
| `src/js/ui.js` | 화면 자판, 키 입력, 공통 도구 |
| `src/js/views.js` | 사용자 고르기, 처음 화면, 연습, 결과 |
| `src/js/game-falling.js` | 단어비, 풍선 팡팡 |
| `src/js/game-race.js` | 타자 레이스 |
| `src/js/app.js` | 화면 이동, 디버그 패널 |

## 만들기와 테스트

```bash
node tests/hangul.test.mjs   # 한글 조합기 + 모든 낱말/문장 입력 검사
node build.mjs               # dist/index.html, dist/artifact.html 생성
```

`dist/index.html`은 브라우저로 바로 열 수 있어요.

## 난이도 조정

- `config.js`의 숫자를 바꾸고 `node build.mjs`를 다시 실행하면 돼요.
- 앱에서 바로 바꿔 볼 수도 있어요.
  - **로고를 빠르게 5번 누르거나** 주소 끝에 `#debug`를 붙이면 디버그 패널이 열려요.
  - 패널에서 CONFIG 값을 고쳐 저장하면 그 기기에서만 다음 판부터 적용돼요.
  - 게임 화면 왼쪽 아래에 현재 속도, 나오는 간격, 화면 속 단어 수가 표시돼요.
  - `LV +1`, `♥ +1`, `GOD`(안 죽음), `END` 버튼으로 바로 시험해 볼 수 있어요.

주요 값:

- `rain.fallSeconds` / `balloon.riseSeconds`: 1레벨에서 화면을 지나가는 시간(초). 클수록 느려요.
- `speedUpPerLevel`, `maxSpeedMul`: 레벨마다 빨라지는 비율과 최대 배수예요. 말도 안 되게 빨라지지 않도록 상한을 둬요.
- `race.cpuRatios`: 컴퓨터 선수 속도예요. 아이의 최근 평균 타수에 대한 배수로 정해요.
- `race.raceKeys`: 경주 거리(타 수)예요.
